# ClientUp sales library

Call scripts for the ClientUp AI pitch, published as static pages for reps to read
on a live call. Live at https://tommychinn.github.io/clientup-script/

Black text is what you say. Blue text is backing context and is not read aloud.
Single-theme white by design — the page must look identical on every device mid-call.

Pages are **generated** from the source Notion doc, not hand-written. See `tools/`
for how to re-sync after the Notion doc changes.

`noindex` throughout: link-accessible, but not indexed by search engines.
